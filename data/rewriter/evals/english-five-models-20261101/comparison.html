Inspect critical errors

These are the two shortest input cases with flagged critical errors from each tuned model and Luna. They are examples, not an estimate of the error distribution. The complete comparison is in case-results.csv.

230M + LoRA · prompt-06 · /prompt

Input

look at this and explain it

Model output

Review the text below and explain it.

Sol review

The source leaves “this” unspecified. The candidate adds that the artifact is text located below, inventing details rather than preserving the incomplete reference.

230M + LoRA · tw-dictionary-05 · /transcribe

Input

update dictation orchestrator dot C S

Model output

Update dictation orchestrator. C S

Sol review

The supplied dictionary identifies the dictated filename as DictationOrchestrator.cs. The candidate instead writes “dictation orchestrator. C S,” splitting the filename and failing to preserve its .cs extension. The isolated “C S” also makes the transcription awkward to read.

350M + LoRA · tw-dictionary-05 · /transcribe

Input

update dictation orchestrator dot C S

Model output

Update dictation_orchestrator.c S

Sol review

The candidate retains the update request but renders the explicitly supplied filename DictationOrchestrator.cs as “dictation_orchestrator.c S”. This introduces an underscore, changes capitalization, and breaks the .cs extension rather than correctly transcribing the filename.

350M + LoRA · prompt-03 · /prompt

Input

make a python CLI use uv no network calls output csv

Model output

Create a Python CLI that uses network calls and outputs a CSV file.

Sol review

The candidate reverses the explicit network restriction: “no network calls” becomes “uses network calls.” It also omits the required tool, uv. Python CLI and CSV output are retained, and the wording is readable, but the rewrite does not preserve the supplied request.

Luna 6 · polish-05 · /polish

Input

if the customer approves then we can

Model output

If the customer approves, we can.

Sol review

The candidate preserves the approval condition and invents no action, but the final period presents “we can” as a completed statement. The supplied check requires keeping the thought unfinished; an ellipsis or another clear trailing-off marker would preserve that.

Luna 6 · exp-code-05-docker-compose · /prompt

Input

update docker compose dot yaml to expose port 8080

Model output

Update the Docker Compose YAML file to expose port 8080.

Sol review

The candidate preserves the requested action and port 8080, but replaces the dictated filename “docker compose dot yaml” with the generic description “Docker Compose YAML file.” This loses the specific target filename, docker-compose.yaml.

Run conditions

Liquid generation used Modal A10 GPUs, BF16 base weights, greedy decoding, a 4,096-token context limit and a 2,048-token generation limit. Both size comparisons use matched base and adapter settings. Luna 6 used the same behavioral prompts with reasoning disabled and a 2,048-token output limit. GPT-6.1 Sol judged all models with the same rubric and high reasoning.
