# Quarantined transport pilot

Do not train on this rehearsal. Its 16 source calls tested generation, parsing, literal checks,
and the judge boundary. Eleven source families failed parsing or literal preservation. The 20
pairs that passed automatic checks also showed repetitive source briefs and artificial requests
when inspected. This entire pilot is excluded from the v1 training release.

The separate `v1-20261027` run uses revised source briefs with explicit roles for quantities and
more natural tasks. The raw rehearsal calls remain here as evidence. A Sol pass alone does not
make this rehearsal a suitable training dataset.
